# 응시 — THE GAZE

1999년 12월, 303호. 의자에 묶인 채 눈을 떴다. 일어설 수 없고, 고개만 돌릴 수 있다.

**멀리 있는 물건을 가만히 바라보면 — 그 애가 가져다준다.**
하지만 죽은 아이의 손이 닿을 때마다 몸의 온기가 빠져나간다.

**플레이:** https://daforce1984.github.io/gaze-horror/

## 게임
- **응시 = 부탁**: 확대해서 오래 바라본 물건을 그 애가 무릎에 가져다 놓는다 (❄ 온기 소모 — 무거운 것, 그 애가 아끼는 것일수록 차갑다). 커튼을 걷어 달라고 하거나, 서랍째 뽑아 오게 할 수도 있다.
- **TV와 CCTV**: 리모컨으로 채널을 돌린다. 7번은 방 구석 CCTV의 실시간 화면 — 의자 밑처럼 직접 볼 수 없는 곳이 보이고, **화면 속 물건을 바라봐도 가져다준다.** 화면 속 의자는… 비어 있다.
- **손에 든 물건**: 3D로 돌려 보며 숨은 곳(밑면 각인, 뚜껑 속 쪽지, 인형 배의 실밥)을 찾고, 다이얼 자물쇠를 돌리고, 태엽을 감고, 조합하고(가위+인형), 대상에 쓴다(가위→밧줄, 열쇠→발목 자물쇠).
- **방이 변한다**: 멀쩡한 저녁 방 → 멈춘 시계 → 썩어 가는 벽, 쌓이는 쓰레기, 벽의 "엄마" 낙서와 작은 손자국, 긁혀 나간 가족사진 → 불이 꺼진 방. 변화는 플레이어가 보고 있지 않은 곳에서 일어난다.
- **그 애**: 처음엔 물건만 저절로 떠 오고, 다음엔 CCTV와 곁눈질에만 보이고, 마침내 직접 걸어와 물건을 건넨다. 오래 바라보면 정신이 무너진다(셰이더: 숨 쉬는 화면·소용돌이·핏줄·환청).
- **마지막**: 사슬을 풀고 일어나 문으로. 그 애를 보고 있으면 멈추고, 눈을 돌리면 다가온다. 그리고 무엇을 건넬 것인가 — 엔딩 4종.
- **숨겨진 이야기**: 자동응답기의 메시지 4개, 달력, 크레용 그림, 쪽지, 신문, 문 안쪽의 손톱자국, TV 11번 뉴스. 기록 7개를 모두 모으면 마지막 진실이 드러난다.
- 플레이 타임 약 10~15분 · 서랍 비밀번호는 매 판 무작위 · 이어하기 지원

## 기술
- HTML5 + **WebGPU** 자체 렌더러: HDR·MSAA, 흔들리는 전구의 큐브 섀도맵, 버텍스 AO, **CCTV 실시간 2차 렌더 → TV 텍스처**, 부패 마스크 셰이더(깨끗한 벽지↔썩은 벽지), 서리·정신 붕괴 포스트 프로세스
- 방·소품·인형·귀신 모델: **Blender** 파이썬 스크립트(`blender/build.py`) → GLB, 쓰레기 더미는 리지드바디 시뮬레이션
- 음성: **ElevenLabs Eleven v3** (아이: Voice Library 아이 캐릭터 보이스, 엄마·앵커: 한국어 보이스)
- 음악: **MiniMax Music 3** (방 앰비언트, 추격, TV 속 동요) · 효과음: **Pixabay** · 오르골 선율과 빗소리는 WebAudio 합성
- 모바일 세로/가로, 드래그·자이로·핀치 확대 지원
- 크레딧: [CREDITS.md](CREDITS.md)

## 개발
```bash
python3 -m http.server 8797
blender -b --python blender/build.py -- all      # 3D 에셋 (Blender 5.x)
uv run --with pillow python tools/convert.py      # 이미지 → WebP
uv run --with soundfile --with numpy python tools/audio_build.py   # 오디오
```
