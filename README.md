# 응시 — THE GAZE

1999년 12월, 303호. 의자에 묶인 채 눈을 떴다. 일어설 수 없고, 고개만 돌릴 수 있다.
그리고 어둠 속에서 아이가 말한다. **“엄마! 일어났다! 우리 숨바꼭질 하자. 엄마가 술래야!”**

**플레이:** https://daforce1984.github.io/gaze-horror/

## 게임 — 규칙은 하나: *이상한 곳을 눌러요*
- **숨바꼭질**: 아이가 숨은 곳(커튼 아래 맨발, 흔들리는 책장, 의자 뒤…)을 찾아 누른다. 눈을 감은 동안 들리는 발소리가 힌트 — 가끔은 거짓말을 한다. 직접 볼 수 없는 곳은 TV에 뜬 방 구석 CCTV로 찾는다.
- **이상현상의 밤 (3회)**: 아이가 방을 조금씩 바꿔 놓는다 — 떠오른 탁자, 저절로 켜진 TV, 뒤집힌 가족사진, 등 뒤에 와 앉은 인형, 열린 문, 커튼 아래 발, 그리고 **보지 않을 때만 기어 오는 아이**. 바뀐 곳을 눌러 원래대로 돌린다. 한꺼번에 3개가 쌓이면 몇 초 안에 하나라도 고쳐야 한다. 변화는 언제나 **플레이어가 보고 있지 않은 곳**에서 일어난다.
- **방이 뒤틀린다**: 밤이 지날수록 그녀의 원룸이 불타 벗겨지며 1999년의 방으로 뒤바뀐다.
- **진실과 선택**: 아이가 가리키는 가족사진 — 사진 속 엄마의 얼굴은… 그리고 두 가지 엔딩: 놓아주기 / 곁에 남기.
- 플레이 타임 약 6~10분 · 레퍼런스: *Observation Duty*, *Exit 8*(이상현상 관찰), 숨바꼭질 놀이 / 귀신 디자인은 J-호러(사다코·가야코) 계열

## 기술
- HTML5 + **WebGPU** 자체 렌더러: HDR·MSAA, 흔들리는 전구의 큐브 섀도맵, 버텍스 AO, **CCTV 실시간 2차 렌더 → TV 텍스처**, 부패 마스크 셰이더(깨끗한 벽지↔썩은 벽지), 서리·정신 붕괴 포스트 프로세스
- 방·소품·인형: **Blender** 파이썬 스크립트(`blender/build.py`) → GLB, 쓰레기 더미는 리지드바디 시뮬레이션
- 귀신: 컨셉 이미지 → **Hunyuan3D 2.1**(ComfyUI, `tools/hy3d.py`)로 3D 재구성 → Blender(`blender/ghost_hy.py`)에서 정리·감량·투영 UV·AO 베이크 (서 있는 자세 / 기어 오는 자세)
- 음성: **ElevenLabs Eleven v3** (아이: Voice Library 아이 캐릭터 보이스, 엄마·앵커: 한국어 보이스)
- 음악: **MiniMax Music 3** (방 앰비언트, 추격, TV 속 동요) · 효과음: **Pixabay** · 오르골 선율과 빗소리는 WebAudio 합성
- 모바일 세로/가로, 드래그·자이로·핀치 확대 지원

## 개발
```bash
python3 -m http.server 8797
blender -b --python blender/build.py -- all      # 3D 에셋 (Blender 5.x)
uv run --with pillow python tools/convert.py      # 이미지 → WebP
uv run --with soundfile --with numpy python tools/audio_build.py   # 오디오
```
