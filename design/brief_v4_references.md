# 레퍼런스 게임 조사 → v4 코어 제안 (Claude → Codex)

사용자 피드백(2026-09-29): "게임이 너무 재미없어. 레퍼런스로 삼을 게임들 평가좋은거 좀 참조해." + 귀신 퀄리티 개선 요청.

## 조사 (평가 좋은 유사 구조)
- I'm on Observation Duty (Steam 95% 긍정): CCTV 감시 중 방의 이상현상(가구 이동~침입자)을 찾아 '보고'. 규칙 단순, 기억·집중·인내만 사용. 미보고 이상현상 4개 누적 시 게임오버. 단점: 너무 미묘한 이상현상은 불공정하게 느껴짐.
- The Exit 8 (Steam 93%): "이상하면 돌아가라, 없으면 계속" 1문장 규칙의 이상현상 찾기. 점프스케어 없이 환경 공포. Observation Duty에서 영감.
- Buckshot Roulette (압도적 긍정): 단순 규칙+기억+아이템으로 모든 선택이 의미있음. "추측할 정보는 늘 있지만 안심할 만큼은 아님". 상대(딜러)의 불완전함이 긴장 유지.
- Inscryption (압도적 긍정): 앉아서 상대와 게임 + 사이사이 방탈출 퍼즐, 상대가 모든 행동에 반응(내레이션).
- FNAF: 고정 좌석, 카메라/문/전력 자원관리, 오디오 단서로 접근 예측.

## v4 코어 제안: "303호의 밤" = Observation Duty × 숨바꼭질
- 밤 19:55 → 06:00 (시간당 약 1분, 전체 ~10분). 1문장 규칙: "그 애가 바꿔 놓은 걸 찾아 눌러요. 4개가 쌓이면 그 애가 온다."
- 이상현상(수아의 장난): 보지 않는 동안 생김. 예) 인형이 책장에서 책상으로 / 인형 고개가 나를 봄 / 액자 속 사람이 사라짐 / 시계가 거꾸로 / TV가 저절로 켜짐 / 커튼이 열림 / 문이 조금 열림 / 벽의 '엄마' 낙서 / 밥상 위 그릇이 두 개로 / 의자 뒤 발자국 / CCTV에만 보이는 아이 / 천장 손자국 …
- 보고: 이상현상을 탭 → "찾았다!" 원상복구(아이 웃음). 오답 탭 → 온기 감소(Buckshot식 비용). 눈으로 못 보는 등 뒤/의자 밑은 TV CCTV로.
- 누적 경고: 활성 이상현상 수가 화면 가장자리 한기/조명으로 표시, 3개면 아이 목소리 경고, 4개면 아이가 옴(숨바꼭질 실패 연출) → 온기 크게 감소.
- 매 2시간 세트피스: 숨바꼭질 라운드(검증된 루프), TV에서 기어나오기(레퍼런스 'The Ring' 연출), 자동응답기 이야기 1문장.
- 시간이 갈수록 방이 썩고 이상현상이 더 기괴·빈번해짐 (기존 decay 시스템 재사용).
- 06:00 생존 → 문이 열림 → 가족사진 선택 엔딩(기존 완결부 재사용).
