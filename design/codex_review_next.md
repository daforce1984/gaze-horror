=== CODEX 542 design_review
hs3 확인. normal 로그의 R2/R3 정답 자막과 CCTV 안내가 현재 상태와 맞게 바뀌었고, 끝까지 연결된 점은 확인됩니다. 다만 이번에는 확장을 잠깐 멈추고 완결판의 선택/시각을 마감하는 게 좋겠습니다.

1. 캐릭터 진단판은 아직 가독성 통과로 보기 어렵습니다. diag_stand_front/close/crouch 모두 얼굴이 검은 기둥처럼 비고, 흰 소매/머리 양옆/몸통에 검정·적색·청색 작은 구멍이 남습니다. 배경 전체에도 강한 필름그레인이 있어 순수 진단판이 아닙니다. 머리카락을 또 늘리기보다 후처리/글리치/페이드 전부0, alpha=1, 단색 불투명 재질, 중간 회색 배경의 캐릭터 1개로 기준점을 먼저 확보하세요. body→hair→텍스처→조명→후처리 순으로 1개씩 켜서 처음 깨지는 단계를 찾는 편이 빠릅니다. 형태 의도가 얼굴 숨김이어도 목/어깨/양팔의 분리는 필요합니다. 현재 가느다란 손이 아니라 긴 소매 막대처럼 읽힙니다. 원본 sprite로 교체 요청이 필요하면 별도 asset 명세로 주세요. 저는 현재 게임 코드를 수정하지 않았습니다.

2. 폰 phone_t3는 화면 왼쪽 커튼 틈으로 아이의 몸 대부분이 드러나며 발은 청색 막대처럼 떠 보입니다. ‘커튼 아래 두 맨발’ 목표와 다릅니다. 발밑 접지 그림자+밑단의 낮은 틈, 몸통은 완전히 가림으로 첫 숨바꼭질을 더 명확히 만들 수 있습니다. 폰에서 눌러야 할 영역을 화면 중앙 쪽에 두고 손가락 한 번으로 성공하는 것은 유지하세요.

3. 마지막 선택의 ↻는 지금까지 180도 돌아보기로 학습된 버튼인데 갑자기 ‘한 번 더 놀기/배드엔딩’이 됩니다. 실수로 엔딩을 고를 위험이 큽니다. 선택 상태에서는 기존 돌아보기 버튼을 숨기고 의미가 명시된 큰 두 버튼 ‘사진 건네기’ / ‘곁에 남기’를 표시하세요. 사진 확대 닫기를 누른 손가락이 선택까지 통과하지 않게 input edge/짧은 release gating도 필요합니다. ‘한 번 더 놀아주기’라는 친절한 행동을 아무 예고 없이 배드엔딩으로 만드는 것은 선택의 함정이 됩니다. 남기 전에 “다시는 문이 열리지 않아도?” 한 문장으로 비용을 알리거나, 좋고 나쁨 대신 ‘놓아주기/함께 남기’ 다른 결말로 표현하는 편이 서사와 맞습니다.

4. ‘나는 엄마’는 아이가 처음부터 엄마라고 불러서 완전히 새로운 반전은 아닙니다. 가족사진은 정체 폭로보다 엄마가 외면한 일을 받아들이는 계기로 쓰세요. 엔딩 전 긴 설명 대신 “문을 잠근 손은 내 손이었다” 같은 한 문장과 손목/문고리의 짧은 연결이 더 직접적입니다. 현재17 엔딩 화면은 본문은 읽히지만 하단 다시하기 설명/행동이 거의 검정이라 찾기 어렵습니다. 고대비 ‘다시 시작’ 버튼 하나를 확실히 보이게 해주세요. 화면상 ‘밧줄이 풀린다’ 자막이 76초까지 DOM에 남는 것은 ending상태에서 깨끗이 숨기기. 로그도 ending_shown/ending_choice/type를 추가해 49.2초 선택과 실제 엔딩 표시를 구분하세요.

5. 이번 자료는 normal만 있어 retry=2.7초 예상 수정은 검증하지 못했습니다. 추가 테스트는 실패→input_enabled 한 회와 최종 선택 두 갈래, 선택 버튼 직전 연타, 폰 세로 각1회면 충분합니다. 자막 수정 정상인 라운드를 계속 반복 테스트할 필요는 없습니다. 그 뒤 인형미끼1종을 붙이고, 무궁화는 사람 플레이 피드백을 받은 다음으로 미루겠습니다. 기능을 계속 늘리는 것보다 현재 4라운드+결말에서 ‘무엇을 눌러야 했나/왜 무서웠나/어디가 지루했나’를 확인할 단계입니다.
