# 응시 (THE GAZE) — 재미 개선 논의 브리프 (Claude → Codex)

## 현재 게임 (라이브: https://daforce1984.github.io/gaze-horror/ , WebGPU 1인칭, 모바일 세로/가로)
- 플레이어는 1999년 아파트 방 의자에 묶여 있음. 고개만 돌리고 확대(zoom)만 가능. 이동 불가.
- 현재 핵심 동사: "멀리 있는 물건을 확대해서 1.4초 응시 → 죽은 아이(수아)가 무릎으로 가져다줌 (온기 감소)".
- 흐름: 리모컨 가져오기 → TV/CCTV → 의자 밑 오르골(CCTV 화면 응시로) → 뚜껑 속 쪽지 → 커튼 → 달력 → 서랍(다이얼 자물쇠) → 태엽 → 가위로 밧줄 → 인형 배에서 열쇠 → 사슬 풀고 일어나 문까지 → 사진을 건네면 엔딩.
- 방은 깨끗한 저녁 → 썩은 방으로 단계적으로 변함. 스토리: 엄마가 밖에서 문을 잠그고 나간 뒤 아이가 기다리다 죽음. 플레이어=엄마.
- 스크린샷: design/current/*.png

## Claude의 진단
1. 첫 1분이 수동적: 자막 읽기 → 리모컨을 "오래 바라보라"는 추상적 지시. 즉각적인 손맛/피드백 없음.
2. 핵심 동사(응시해서 가져오기)가 느리고 반복적이며 실패/긴장이 없음 → 퍼즐 체크리스트처럼 느껴짐.
3. 위협(귀신)이 수동적. 플레이어의 선택이 결과를 바꾸지 않음. 긴장 곡선이 평평함.

## Claude의 초안 제안: "엄마랑 놀자" — 아이가 원하는 놀이 = 미니게임 챕터
귀신 아이는 20년 동안 엄마를 기다렸고, 이제 엄마(플레이어)와 "놀고" 싶어함. 각 놀이는 규칙이 한 문장이고 시작 5초 안에 조작함.
1. 숨바꼭질: "엄마가 술래! 열 셀 동안 눈 감아" → 화면 암전 카운트 → 방 어딘가에 숨은 아이를 30초 안에 찾아 응시 ("찾았다!"). 힌트: 킥킥 소리(입체음향), 커튼 아래 발, 책장 틈 머리카락, 의자 밑(CCTV로만). 라운드마다 어려워지고 그녀가 반칙함. 실패 = 온기 감소+점프스케어.
2. 무궁화 꽃이 피었습니다: 플레이어가 술래 — 벽(TV)을 보고 있는 동안 아이의 목소리로 구호, 그 사이 아이와 인형들이 다가옴. 돌아봤을 때 움직이는 걸 잡으면(응시) 뒤로 돌아감. 닿으면 패배.
3. 틀린 그림 찾기: "눈 감았다 떠. 뭐가 바뀌었게?" → 방의 한 가지가 바뀜(방이 썩는 연출과 결합) → 바뀐 곳을 응시로 지목.
4. (기존) 가져오기/조합 퍼즐은 놀이의 보상 아이템 사용으로 축소.
5. 마지막: 문 앞에서 무엇을 건넬지 선택 → 엔딩.
놀이마다 방이 한 단계씩 기괴해지고, 이긴 보상으로 이야기 조각(자동응답기, 달력...)이 풀림.
